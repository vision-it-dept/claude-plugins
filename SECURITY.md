# Security Policy

## Scope

This policy covers vulnerabilities in the plugins published in this repository, such as a plugin instruction or script that could expose a user's credentials or confidential results, or run unintended commands on a user's machine.

The following are not covered:

- Findings about the websites or systems you assess with a plugin. These are results about your target, not vulnerabilities in the plugin. Do not send them to us.
- False positives, missed findings, and guidance that could harm the target system. Report these as public [issues](https://github.com/vision-it-dept/claude-plugins/issues/new/choose) so that other users can see them.

## Reporting a vulnerability

Report plugin vulnerabilities privately with GitHub's [private vulnerability reporting](https://github.com/vision-it-dept/claude-plugins/security/advisories/new) (**Report a vulnerability** on the **Security** tab). Do not open a public issue.

You may write your report in English or Japanese.

## Supported versions

Only the latest release of each plugin is supported. Fixes are made in a new release.

## Response

Reports are handled on a best-effort basis. We do not commit to a response time or a fix date.
